# LiveBetter 隐私政策

> 文档编号：DEV-LB-003 ｜ 版本：v1.1 ｜ 生效日期：2026-11-25
>
> 适用范围：LiveBetter Android 应用（包名 `com.livebetter.app`）及其开源代码仓库。

## 1. 一句话说明

LiveBetter 不收集、不上传、不共享任何个人数据。你的打卡记录只保存在你自己的手机里；只有在你点击「检查更新」或应用自动检查更新时，才会向 GitHub 请求公开的版本信息。

## 2. 我们如何处理数据

| 数据 | 存放位置 | 是否离开设备 |
| --- | --- | --- |
| 打卡项、每日记录、设置 | 应用私有目录下的本地 SQLite 数据库 | 否 |
| 卡片背景图片 | 应用私有目录（压缩后 ≤ 300KB） | 否 |
| 应用锁密码 | 仅保存加盐哈希，不存明文 | 否 |
| 迁移前自动备份 | 应用私有目录 `backups/`（保留最近 3 份） | 否 |
| 更新安装包缓存 | 应用缓存目录 `updates/`，安装后由系统回收 | 否 |
| 导出的 JSON 备份 | 由你选择保存或分享的目标位置 | 仅在你主动操作时 |

## 3. 权限说明

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | 仅用于检查更新与下载新版安装包，不用于收集或上传任何数据 |
| `REQUEST_INSTALL_PACKAGES` | 下载完成并校验通过后，拉起系统安装器完成升级 |
| `POST_NOTIFICATIONS` | 发送每日本地提醒 |
| `RECEIVE_BOOT_COMPLETED` | 重启后恢复已安排的提醒 |
| `USE_BIOMETRIC` / `USE_FINGERPRINT` | 应用锁解锁；不可用时回落到应用内密码 |
| 相册选择（系统照片选择器） | 选择打卡卡片背景图，仅读取你主动选择的图片 |

应用不申请定位、通讯录、相机权限，不含任何广告、统计或崩溃上报 SDK。

## 4. 联网与第三方

- **检查更新**：应用启动时（最多每 24 小时一次）与手动点击「检查更新」时，会访问 GitHub 公开接口 `api.github.com` 读取 LiveBetter 仓库最新 Release 的版本号与说明。该请求不携带账号、设备标识或任何打卡数据，GitHub 作为服务方会按其自身政策记录常规访问日志。
- **下载安装包**：仅在你确认更新后，从 GitHub Releases 下载 APK 与同名 `.sha256` 校验文件，校验通过后才拉起系统安装器；下载文件存放于应用缓存目录，安装完成或失败后会被系统回收。
- 除此之外，应用不集成任何第三方数据服务，开源依赖库仅在本地运行，不发起网络请求。

## 5. 数据删除

- 「我的 → 设置 → 清除全部数据」会删除本机全部记录与设置。
- 更新安装包缓存在应用私有缓存目录，系统会自动回收，也可在系统设置中清除应用缓存。
- 卸载应用会一并删除应用私有目录下的数据库、图片与备份。
- 导出的 JSON 文件需要你自行删除。

## 6. 儿童隐私

应用不面向 13 岁以下儿童，也不收集任何可识别个人身份的信息。

## 7. 政策变更

政策更新会随版本发布在本文件与仓库中，重大变更会在 Release 说明中标注。
